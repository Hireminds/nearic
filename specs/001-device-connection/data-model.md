# Модель подключения устройства

Формат и ограничения полей на проводе определяются в [контракте обмена](contracts/device-service.md).

| Сущность | Поля и связи |
| --- | --- |
| Device | Идентификатор, модель, версия, фактически доступные функции. На сервисе запись связана с доступом устройства и после регистрации с аккаунтом. У зарегистрированного устройства может быть один активный разговор |
| WiFiSetup | Локальная сессия с временными реквизитами доступа, кандидатом настроек сети и результатом проверки. Последняя рабочая конфигурация хранится на BOX отдельно от сессии |
| DeviceAccess | Отдельные реквизиты, которые BOX получает автоматически по сети. Отзыв остановит обмен, не удаляя локальную конфигурацию Wi-Fi |
| RegistrationCode | Одноразовый код, выданный сервисом конкретному Device. Действующий код подтверждает добавление устройства в аккаунт Nearic. После регистрации код погашается |
| Binding | Идентификатор конкретного поколения привязки. Связан с владельцем, разрешением коннектора и существующим разговором. Действует до явной смены или отзыва |
| Operation | Идентификатор, тип, снимок Binding, состояние, результат. Повторное получение ничего не меняет после завершения или отмены; поздний результат не меняет адресата |
| Release | Версия и совместимость образа, адрес скачивания, размер и контрольная сумма. Происхождение подтверждает подпись образа |

Состояния устройства различают настройку сети, недоступную сеть, поиск сервиса,
ожидание регистрации, зарегистрированное устройство и активную привязку.
Успешный свежий ответ требует
завершения своего запроса на BOX. Статус присутствия сервиса и результат запроса
учитываются отдельно.

Загрузка образа не меняет текущую версию. После переключения обновление ожидает
локальной проверки работоспособности. Успех подтверждает новый образ, сбой оставляет
последнюю подтверждённую версию.
