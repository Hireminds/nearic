# Проверка спецификации подключения устройства

Модельное ревью [спецификации подключения](../spec.md) учитывает сценарий
первого запуска с телефона и регистрации в аккаунте Nearic.

- [x] Сценарии описывают наблюдаемое поведение и приоритет. Для каждого есть отдельный прогон.
- [x] Требования сформулированы в терминах пользователя и устройства. Выбор реализации вынесен в план.
- [x] USB-установка, настройка с телефона, регистрация, оба пути привязки, живой статус и OTA покрыты критериями.
- [x] Сценарии проверяют неверный пароль, смену сети, обрыв, просроченный код, поздний ответ и неудачную загрузку.
- [x] Указаны зависимости от сервиса и физической платы. Граница с последующими функциями определена.
- [x] Открытые детали реализации переданы в проектирование. Продуктовый скоуп определён.
