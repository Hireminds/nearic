# Доменные спецификации прошивки

Каждая директория описывает устойчивую доменную область. `spec.md` — контракт поведения;
`plan.md` и `tasks.md` — производные материалы последнего изменения. История — в Git,
важные технические решения — в [ADR](../docs/decisions/README.md) и контрактах.

- [Подключение устройства](001-device-connection/spec.md) описывает настройку BOX,
  привязку к разговору, проверку связи и обновление.

Настройка Spec Kit описывается в руководстве участника. Draft-материалы в `docs/`
сохраняют свой статус до согласования.

Изменение поведения начинается с правки соответствующей спеки. Для новой области агент
использует стандартный spec-template и явную доменную директорию. Один запуск Spec Kit
имеет одну активную директорию; междоменные изменения связывают затронутые требования
ссылками и проверяют каждый затронутый контракт. Общий скоуп остаётся в проектной системе.

Практические инструкции: [CONTRIBUTING.md](../CONTRIBUTING.md).
