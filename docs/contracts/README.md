# Граница прошивки и сервиса

Статус: Draft. Описывает предмет согласования протокола между устройством и Nearic Service.

Устройство объявляет доступные возможности, принимает команды и сообщает о выполнении, отмене, ошибке или неопределённом результате. Пользовательский ввод относится к доставленному разговору, а экранный ввод — ещё и к идентификатору и версии показанного интерфейса.

Перед реализацией интеграции требуется согласовать версию схемы, идентификаторы операций и событий, подтверждения, повторную доставку и поведение при потере связи. Каталог MCP и входящие события агентного клиента поддерживаются в репозитории сервиса.

[Проект контракта v1](../../specs/001-device-connection/contracts/device-service.md)
детализирует подключение BOX, выдачу кода, адресованный запрос состояния и OTA.
