# Требования к прошивке Nearic

Статус: Draft. Предварительные требования к устройству для детализации в [сценариях](flows/README.md) и доменных контрактах. Текущая готовность указана в [README](../README.md#состояние).

| ID | Требование |
| --- | --- |
| R-01 | Первая референсная аппаратная платформа — ESP32-S3-BOX-3B |
| R-08 | Устройство показывает настраиваемый аватар агента с состояниями и анимацией |
| R-09 | Экран поддерживает вывод и взаимодействие с произвольной HTML/CSS/JS-страницей агента; способ исполнения определяется отдельно |
| R-10 | Интерфейс использует токены, дизайн-систему и небольшую библиотеку компонентов Nearic |
| R-11 | После первой USB-установки устройство автоматически получает совместимые релизы по Wi-Fi; предусмотрены проверка образа, сохранение настроек, откат и USB-восстановление |
| R-12 | Аватары, ресурсы и интерфейс по возможности обновляются независимо от прошивки |

Устройство принимает речь и касания пользователя, воспроизводит звук, отображает состояние и передаёт ввод сервису. Прошивка объявляет фактические возможности платы и сохраняет адресацию разговора для передаваемых пользовательских событий. [Граница с сервисом](contracts/README.md) описывает вопросы, которые потребуют согласования до интеграции.

Первый этап использует готовую плату. Проектирование серийного устройства и поддержка дополнительных плат требуют отдельного решения.
