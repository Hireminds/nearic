# Проверки прошивки

Статус: требования к проверкам. Выполненные проверки и поддерживаемые версии фиксируются для соответствующей сборки.

| Уровень | Что подтверждает |
| --- | --- |
| Документы | Ссылки, непротиворечивость требований, зависимости и различение Draft и реализации |
| Контракты | Схемы команд и событий, подтверждения, отмена и поведение при обрывах |
| Устройство | Динамик, микрофоны, касания, память, связь и пользовательские состояния |
| Экран | Отображение 320×240, реальные касания, читаемость, задержка и базовое состояние при сбое интерфейса |
| OTA | Успешное обновление, повреждённый образ, обрыв загрузки, неудачный запуск, откат и сохранение настроек |

Для воспроизводимой проверки фиксируются модель и ревизия платы, версии прошивки и смежных компонентов, топология сети, шаги, результаты и ограничения. Аппаратную проверку проводят на устройстве. Публикуемые материалы не содержат секретов, персональных данных и пользовательских аудиозаписей. Для аудиотестов используются подготовленные тестовые записи.
