# Дизайн-система устройства

Статус: Draft. Требование использовать собственные токены и компоненты согласовано; визуальный стиль и численные значения ещё не утверждены.

## Поверхность

Первый профиль: сенсорный экран 320×240, диагональ 2,4 дюйма. Для браузерного предпросмотра нужно явно согласовать viewport, масштаб и преобразование координат касаний.

## Слои

1. Токены: цвета, шрифты с кириллицей, типографика, размеры касаний, отступы, радиусы, движение и состояния.
2. Небольшая библиотека: Screen, Row, Column, Text, Icon, Image, Button, Card, ChoiceList, Toggle, Slider, Progress, Avatar, Status.
3. Произвольная композиция: агент создаёт HTML/CSS/JS с использованием токенов и может добавлять собственные элементы.

Предлагаемые стартовые значения для проверки на устройстве: текст 18–20 px, заголовок 24–28 px, высота области нажатия от 44 px, шаг отступов 4 px, поля экрана 8–12 px. Это гипотезы, а не принятый стандарт.

## Аватар

Полный экран; компактное присутствие рядом с UI; скрытое состояние. Базовые состояния: ожидание, слушает, думает, говорит, связь недоступна. Локальная анимация речи и её синхронизация проверяются вместе с аудио.

## Генерация

Агент получает версию дизайн-системы, токены, каталог, примеры и профиль устройства. Перед публикацией доступен предпросмотр и отчёт о поддерживаемых проверках. Семантическая приёмка и реальная читаемость на устройстве остаются отдельными проверками.

Способ доставки и исполнения страницы согласовывается с Nearic Service. На устройстве проверяются читаемость, расположение касаний, задержка и работа экрана одновременно с аудио.
