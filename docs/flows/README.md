# Сценарии устройства

Статус: Draft. Сценарии конкретизируют [требования к прошивке](../PRODUCT.md). Привязка к разговору описана в [спецификации подключения](../../specs/001-device-connection/spec.md).

| Сценарий | Наблюдаемое поведение |
| --- | --- |
| Настройка и связь | Пользователь настраивает Wi-Fi с телефона, в том числе после смены сети. BOX показывает состояние связи и сохраняет последнюю рабочую настройку |
| Регистрация | BOX показывает одноразовый код от сервиса. Пользователь подтверждает его и видит устройство в своём аккаунте Nearic |
| Привязка | Пользователь выбирает зарегистрированный BOX из существующего разговора |
| Проверка связи с агентом | Из связанного разговора запрашивается состояние. BOX отвечает на текущий запрос, а сервис возвращает результат в этот разговор. При недоступности BOX сервис сообщает об отсутствии свежего ответа |
| Голос | Устройство показывает состояние микрофона и воспроизведения. Обрыв связи не выдаётся за подтверждённую доставку или завершение |
| Аватар и экран | Устройство отображает назначенный аватар и интерфейс. Событие ввода относится к показанной версии экрана и нужному разговору |
| Обновление | После публикации совместимого релиза устройство автоматически скачивает и проверяет его по Wi-Fi. После установки настройки сохраняются. При неудачном запуске устройство возвращается к подтверждённой рабочей версии |

AC-6: Когда новая прошивка не проходит проверку работоспособности, устройство возвращается к подтверждённой рабочей версии.

Полные сценарии должны описывать шаги, отмену, ошибки и проверку на устройстве. Отказы сетевой доставки уточняются на границе с сервисом.
